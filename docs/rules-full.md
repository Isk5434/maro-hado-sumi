# まろいぬの覇道 通常版ルール（ルール説明用）

紙の「通常版改訂」ルールブック（2026年11月時点）の写真と、得点計算表の写真から書き起こしたもの。
ルール説明（src/tutorial/fullSteps.tsx）はこの内容に合わせている。ゲーム本体は今のところ短縮版だけ。

## 短縮版との違い
- 寺カード 8枚（村のふち＝四辺にしか置けない）
- 僧コマ 18個（合戦の強さ 3）
- 村の祭・町の祭カード 各2枚（出たら祭置き場へ。終わりまで置いたまま。同じ祭がまた出たら何も起きない）
- お米ポイント：農地に農民を置くと1つもらえる。ゲーム終了まで持っていれば1つ1点
- 特殊効果カード 4種×各4枚：番の最初にお米1つで使う。1ターン1枚まで、それぞれ1ゲーム1回
  - 左隣の人は一回休み / 左隣の人のカードを2枚外す / キープと村のカードを交換 / 城の上の4枚を並べなおす
- 合戦：人物コマを最大3人・最低1人出す（短縮版は3人以上いれば必ず3人）
- 順番はじゃんけんで勝った人から時計回り
